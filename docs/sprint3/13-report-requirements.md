# S3-13. Требования к отчёту по партии и сводке для руководителя

Статус: **черновик на утверждение PO** (issue #43). Реализация — S5-04 (#61), S5-05 (#62).

## 1. Отчёт по партии (PDF)

Формируется с экрана партии кнопкой «Отчёт PDF» для активной (на текущую дату) и закрытой партии. Доступ — все роли, кроме оператора чужого птичника.

| Раздел | Содержание | Источник |
|--------|------------|----------|
| Шапка | площадка, птичник, код партии, кросс, инкубаторий, даты посадки и сдачи, возраст, дата формирования, кто сформировал | партия |
| KPI | посажено, сдано/живых, сохранность, падёж и выбраковка (гол и %), не учтено при сдаче, живая масса, FCR, ADG, EPEF, длительность | S4-01 (`KpiFormulas`) |
| План-факт | таблица и график веса по взвешиваниям против нормы кросса, отклонение % | S4-02 |
| Учёт по неделям | падёж, выбраковка, корм, вода за каждую неделю, накопительно | ежедневный учёт |
| Инциденты | число по категориям и приоритетам; список CRITICAL и HIGH: время, описание, время реакции, кто закрыл | инциденты |
| Отклонения микроклимата | по каждому показателю: суммарные минуты вне нормы, худшее значение | движок правил (Influx) |
| Нормы | версия норм, по которой считалась партия | `norms` |

Показатель без данных — «—» с пояснением («нет взвешиваний»), не 0. Числа — с округлением как в S3-08.

## 2. Сводка для руководителя

Экран и выгрузка PDF «Сводка по площадке», роли MANAGER и ADMIN (технолог — только чтение).

| Блок | Содержание |
|------|------------|
| Птичники | строка на птичник: партия, возраст, живых, сохранность, вес против нормы %, FCR, открытые инциденты (CRITICAL/HIGH), статус «в норме / внимание / критично» |
| Итог площадки | поголовье, средняя сохранность и FCR (взвешенные по поголовью), открытые инциденты |
| Реакция | медиана и 90-й перцентиль времени реакции за 7 дней, просроченные по SLA |
| Закрытые партии за период | KPI каждой и среднее, сравнение с прошлым периодом |

Период — неделя / месяц / произвольный. Сортировка по статусу (критичные сверху).

## 3. Вопросы к PO

1. Нужна ли подпись технолога в PDF и логотип заказчика.
2. Сводка — только экран или ещё рассылка по расписанию (почта/Telegram, S5-01).
3. Показывать ли стоимость корма и себестоимость — нужны цены, их сейчас нет в системе.
