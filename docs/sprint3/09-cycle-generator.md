# S3-09. Генератор цикла партии

Статус: **готово** (issue #39). Скрипт `sensorImitation/cycle_generator.py`, только стандартная библиотека Python 3.10+.

Отыгрывает партию целиком через API, как это делали бы люди и датчики:

1. Сажает партию в указанный птичник с датой посадки «сегодня − `--days`».
2. Вносит учёт за каждые сутки: падёж в пределах допустимого по норме, выбраковку (15–40 % от падежа), корм по кривой кросса × живое поголовье × продуктивность площадки (0,95–1,0), воду 1,7–1,95 × корм.
3. Раз в неделю и в последний день — контрольное взвешивание 100 голов (вес по кривой кросса × продуктивность, однородность 78–88 %).
4. Шлёт показания всех активных датчиков птичника за последние `--telemetry-days` суток (по умолчанию 2, шаг `--step` 10 мин) пачками по 500: температура и влажность по норме для возраста с суточным колебанием, CO2 и аммиак растут с возрастом, освещённость по программе освещения (тёмный период с 22:00).
5. `--close` — закрывает партию сегодня: сдано = живое поголовье минус недостача 0–30 гол, вес по кривой кросса.
6. `--incidents` — подмешивает отклонения для демонстрации правил: первый датчик температуры +2,2 °C последние 50 минут, последний датчик птичника молчит 45 минут, падение корма на 15 % в последние сутки (для правила S4-05).

Нормы берутся из тех же файлов, что и в системе: `norms-v1.csv` и `docs/sprint2/norms-production.csv`. `--seed` даёт одинаковые данные при повторе.

## Запуск

```bash
# Ross 308 на 21-й день в «Птичнике 4» с отклонениями, затем нажать «Проверить сейчас» на экране «Нормы и правила»
python3 sensorImitation/cycle_generator.py --password change-me-local --api-key local-ingest-key --days 21 --incidents

# Закрытая партия Cobb 500 на 40 дней в другом птичнике
python3 sensorImitation/cycle_generator.py --password change-me-local --api-key local-ingest-key \
  --house-code 1-05 --breed COBB_500 --heads 25000 --days 40 --close

# Без отправки: записать все запросы в файл
python3 sensorImitation/cycle_generator.py --dry-run /tmp/cycle.json --incidents --close
```

`--api-key` — значение `TELEMETRY_INGEST_API_KEY` из `.env` backend. В птичнике не должно быть активной партии.
