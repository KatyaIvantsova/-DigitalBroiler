## Что показал прогон

- Пример S1-04 совпал с расчётом вручную: 96,50 %, 1,634, 64,0 г/сут, 384.
- **Вопрос к PO (случай 4):** при недостаче на сдаче сохранность (сдано / посажено = 96,94 %) и процент потерь по учёту ((D + C) / N₀ = 2,78 %) не дают в сумме 100 %. Предлагаем показывать недостачу отдельной строкой «Не учтено при сдаче, гол» в отчёте по партии (S5-04).
- В день посадки FCR = 0 (корма ещё не было) — интерфейс должен показывать «—», а не 0,000. Учесть в S4-04.
