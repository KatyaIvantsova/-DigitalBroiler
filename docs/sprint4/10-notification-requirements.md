# S4-10. Требования к оповещениям

Статус: **черновик на утверждение PO и площадкой** (issue #53). Критерий готовности — утверждённая матрица эскалации. Реализация — S5-01 (Telegram, подписки), S5-02 (эскалация, дежурства).

## 1. Каналы

| Канал | Для чего | Когда |
|-------|----------|-------|
| Экран системы (баннер, реестр) | все инциденты | сразу, уже работает |
| Telegram-бот | CRITICAL и HIGH по своим птичникам | сразу при создании или повышении |
| Звонок / SMS | только эскалация CRITICAL, если никто не взял | после SLA реакции; зависит от провайдера — вопрос 3 |
| Почта | ежедневная сводка руководителю (S5-05) | раз в сутки, 07:00 по времени площадки |

## 2. Кто получает

Подписка — на птичник. Оператор подписан на свои птичники автоматически (по назначению в профиле), технолог и ветврач — на все птичники площадки, руководитель — только эскалации и сводку.

| Тип инцидента | Оператор птичника | Технолог | Ветврач | Руководитель |
|---|:-:|:-:|:-:|:-:|
| Микроклимат, освещение | ✓ | ✓ | | |
| Нет данных от датчика | ✓ | ✓ | | |
| Падёж, состояние стада | ✓ | ✓ | ✓ | |
| Корм, вода | ✓ | ✓ | | |

## 3. Матрица эскалации

Время реакции — от создания инцидента до статуса «В работе». SLA реакции сейчас 30 минут (аналитика инцидентов).

| Приоритет | Сразу | Не взяли за | Эскалация к | Ещё не взяли за | Эскалация к |
|-----------|-------|-------------|-------------|-----------------|-------------|
| CRITICAL | оператор, технолог (Telegram) | 15 мин | дежурный технолог (Telegram + звонок) | 30 мин | руководитель площадки (звонок) |
| HIGH | оператор (Telegram) | 30 мин | технолог | 2 ч | руководитель (Telegram) |
| MEDIUM | экран | 4 ч | технолог (Telegram) | — | — |
| LOW | экран | — | — | — | — |

Повторное уведомление по тому же инциденту — не чаще раза в 15 минут; повышение приоритета движком правил уведомляет заново.

## 4. Дежурства

- Расписание дежурств технологов на неделю: кто дежурит в каждую смену (день 08:00–20:00, ночь 20:00–08:00 по времени площадки). Ведёт руководитель на экране «Дежурства» (S5-02).
- Ночью оператора, если он не на смене, не будим: CRITICAL сразу идёт дежурному технологу.
- Нет дежурного в расписании — эскалация идёт руководителю, на главной предупреждение «нет дежурного».

## 5. Вопросы к PO и площадке

1. Подтвердить пороги эскалации (15 / 30 мин для CRITICAL).
2. Кто руководитель для эскалаций на пилоте, есть ли заместитель.
3. Нужен ли звонок / SMS на пилоте и через какого провайдера (стоимость).
4. Можно ли использовать Telegram на площадке (политика безопасности заказчика) или нужен другой мессенджер.
