## Приёмочные сценарии для QA (по партии)

1. Посадка: птичник, кросс, дата, поголовье, вес. Ожидание: партия «Активна», возраст = сегодня − дата посадки.
2. Посадка с будущей датой: «Запланирована», в день посадки становится активной (проверка раз в час).
3. Учёт за день: падёж, выбраковка, корм, вода. Повтор за ту же дату — ошибка; дата раньше посадки или в будущем — ошибка.
4. Списание больше поголовья — ошибка с понятным текстом.
5. Правка учёта задним числом — запись в «Истории изменений» с автором, временем, «было → стало».
6. Взвешивание: зона только из птичника партии.
7. Закрытие: сдано не больше живого поголовья; после закрытия оператор не может править учёт, технолог может.
8. Оператор без назначения не видит партий; админ назначает птичник — партия появляется.
9. Блокировка пользователя — вход невозможен.
